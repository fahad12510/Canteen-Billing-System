
# Campus Canteen Billing System

A simple Python project for calculating canteen bills.

## Features
- Displays four menu items with prices.
- Allows multiple orders.
- Calculates subtotal and total quantity.
- Applies a 10% discount on bills of PKR 1,000 or more.
- Displays the final bill.

## How to Run
1. Install Python.
2. Open the project folder in a terminal.
3. Run the following command:

   python main.py
